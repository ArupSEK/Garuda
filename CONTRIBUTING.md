# Contributing

Open an issue describing the safe assessment use case before adding a scanner or check. Changes must use typed, testable modules; fixed subprocess argument arrays; explicit timeouts; redaction; fixture-based tests; and updated policy/documentation.

Do not contribute exploit execution, brute-force behavior, denial-of-service tests, unrestricted fuzzing, credential attacks, persistence, evasion, or destructive functions. Run `pytest` and `ruff check app dashboard tests` before submitting a pull request.
